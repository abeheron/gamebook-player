# Content rights

This repository does not choose a license. Adding one is a decision for the repository owner.

`tests/fixtures/lantern-stair.json` is original sample text written for this foundation. It is not a published gamebook. The `rights` field on the book says so, and the reader shows that note. Do not replace it with a license the owner has not chosen.

Do not add Project Aon books, Lone Wolf text, or other people's gamebook text or art. A download link, or a non-commercial reading license, is not permission to redistribute the book in this repository.

GNAT rules are by David M. Donachie and are published under CC BY-SA 4.0. That license is not the same as a book's text and art license. `src/systems/gnat/demo.json` credits that source. It records these facts from the rules chapter cited in the repository audit: the ten skill names, +2 for a basic skill the character has, −2 when a test names a skill they lack, a start of two basic skills, 10gp, one ration, and an unlimited coin pouch. Climbing and Linguistics are a sample choice of those two skills. Stat maxima in the file remain sample bounds. The file does not copy rules prose, book text, or art. Fortune is displayed and has no spend action. This does not relicense anyone else's work.

The icons in `public/icons` and `src-tauri/icons` are plain generated images made for this repository, not third-party art.

Before any public release or open-source license, import rules and the Project Aon terms still need a separate review. That review is not done here.
