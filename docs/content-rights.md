# Content rights

This repository does not choose a license. Adding one is a decision for the repository owner.

`tests/fixtures/lantern-stair.json` is original sample text written for this foundation. It is not a published gamebook. The `rights` field on the book says so, and the reader shows that note. Do not replace it with a license the owner has not chosen.

Do not add Project Aon books, Lone Wolf text, or other people's gamebook text or art. A download link, or a non-commercial reading license, is not permission to redistribute the book in this repository.

GNAT rules are by David M. Donachie and are published under CC BY-SA 4.0. That license is not the same as a book's text and art license. `src/systems/gnat/demo.json` uses the stat names Talent, Vitality, and Fortune and credits that source. It is an incomplete original configuration for the sample. The starting numbers and maxima are sample values. The design note's "Fortune 3 (max 3)" is not treated here as proof that only Fortune has that maximum. This sample never spends Fortune. A later PDF audit, cited in [the roadmap](roadmap.md), does state a one-point reroll and a Fortune cap of 3. That audit is not implemented in this demo file. The file does not copy the rules text. Fortune is displayed and has no spend action. A later file that actually reproduces the GNAT rules would be a CC BY-SA adaptation and would need to carry that license and attribution. This demo file does not do that, and it does not relicense anyone else's work.

The icons in `public/icons` and `src-tauri/icons` are plain generated images made for this repository, not third-party art.

Before any public release or open-source license, import rules and the Project Aon terms still need a separate review. That review is not done here.
