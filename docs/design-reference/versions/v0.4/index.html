Rules: Temple of the Skull God

Summary of the GNAT rules as listed in the app's design doc. It isn't the book's own wording; check the book for exact rules. GNAT rules by David M. Donachie, CC BY-SA 4.0.

Character

  • Talent 9, Vitality 3, Fortune 3 (max 3).
  • Each Wound costs 1 Vitality (the doc's fight sample).
  • Dice: 2d6.

Tests

  • Roll 2d6; pass if the total ≤ Talent ± modifier.
  • Double 1 always passes; double 6 always fails.
  • Spend Fortune to re-roll a die.
  • Advantage / Disadvantage re-rolls.

Skills

  • +2 to a test if you have the skill, −2 if not.
  • Item bonuses: only the highest one counts.

Fighting

  • “Fight N rounds at −X”: a test at −X each round.
  • Each failed round costs one Wound; a fumble (double 6) adds a Wound.
  • Weapons and shield are listed as modifiers; armour ignores N wounds per adventure.

Items and spells

  • Items, treasure and gold. Heavy items limited to 2 × max Vitality.
  • Spells come on scrolls: test vs 10; the scroll is destroyed when cast.

Keywords, titles, ticks

  • Keywords are gained in one section and checked in another; they survive losing items.
  • Titles carry between books.
  • Tickboxes: “If ticked, turn to …; if not, tick it and read on.” Some sections have several boxes. Section 574 is a reference list of keywords and tickboxes.

Rest and advancement

  • Rest with rations.
  • XP buys stats and skills.

Not in the design doc / not modelled

  • Exact Advantage/Disadvantage, weapon, shield and armour values.
  • What happens at Vitality 0.
  • How much rest restores; XP costs.
  • How tests vs 10 apply modifiers.
  • How much Fortune a re-roll costs.

The prototype shows these as gaps rather than guessing. Demo-only choices on the Test screen: a re-roll costs 1 Fortune, the fight is fixed at 3 rounds at −2, and rolling stops at Vitality 0. Advantage/Disadvantage, weapons, shield, armour, spells, rest and XP are not implemented.
